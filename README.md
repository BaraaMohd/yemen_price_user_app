# Yemen Price - User App

Flutter Android app for regular users.

## Download (Outside Play Store)

Use the latest APK from GitHub Releases:

- https://github.com/BaraaMohd/yemen_price_user_app/releases/latest/download/app-user-release.apk
- If this link returns `404`, the repository/release is private. Use your public landing-page download link instead.

## Install Steps for End Users

1. Download the APK on Android.
2. Open the downloaded file.
3. If prompted, allow `Install unknown apps` for your browser/files app.
4. Tap `Install`.
5. Open the app and sign in.

## Update Steps

1. Download the new APK from the same Releases link.
2. Install it over the existing app (no uninstall needed).
3. Keep data and login as usual.

## Important

- Package name: `com.pricepulse.yemen`
- Updates require the same signing key and a higher `versionCode`.

## Run Locally

```bash
flutter pub get
flutter run
```
